# Amatu Slides

Presentasi di browser ala Google Slides + fitur PowerPoint — https://amatu-id.github.io/presentation/

- Editor slide: filmstrip, tata letak, tema (16 tema + warna/font kustom), master, panduan pintar, kisi, zoom.
- Objek: kotak teks, WordArt, 36 bentuk, garis/panah/konektor, gambar (masker, koreksi, pangkas), tabel, bagan, ikon, video YouTube, diagram SmartArt.
- PowerPoint: animasi (masuk/penekanan/keluar, urutan klik), transisi termasuk Morph, tampilan penyaji + jendela penonton, pena/stabilo/laser, latihan pengaturan waktu, penyortir slide, bagian, Designer (ide desain), format painter, pipet warna, panel seleksi.
- File: kata sandi saat dibuka, penyiapan halaman (ukuran & margin slide), cetak/PDF dengan margin halaman & handout, ekspor .pptx (dengan transisi), PNG/JPEG, impor .pptx.
- Bagikan: tautan "Lihat saja" (pelihat) dan "Bisa mengedit" (editor) yang tersinkron (Supabase `amt_share`, app `presentation`).

Vanilla ES modules, tanpa build. `js/live.js` identik dengan Amatu Docs/Sheets.
